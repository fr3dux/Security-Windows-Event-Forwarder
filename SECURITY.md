# Security Policy

## Supported versions

Security fixes are applied to the latest source version. Version 0.1.0 is
preserved for reproducibility but is not expected to receive fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security-advisory feature for this repository and include:

- affected version and deployment mode;
- reproduction steps;
- expected and observed behavior;
- impact and any suggested mitigation.

Do not include production event data, credentials, internal addresses, Active
Directory names, or Darktrace appliance details in the report.

This community project is not supported by Darktrace. Vulnerabilities in a
Darktrace product must be reported through Darktrace's official channels.
